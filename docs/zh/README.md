# 🎬 导演模拟器：场景构建器 (Director Simulator: Scene Builder)

**Unity Sandbox Director** – 一个位于 Unity 内的沙盒工具，允许您在 Unity 编辑器中**扮演导演的角色**。构建环境、放置角色、定位摄像机、录制场景并进行分享。专为想要快速创建电影片段且无需视频编辑经验的**电影制作人、游戏制作人和教育工作者**而设计。

---

## 🚀 快速开始 (Quick Start)
1. 克隆该仓库并在 Unity 2021.3+ 中打开（推荐使用 URP）。
2. 打开 `Window → Placement System → Prefab Creator` 创建您的第一个预制件。
3. 使用 **MiniTimeline**（`Tools → Mini Timeline` 窗口）创建动画、摄像机移动并导出视频。
4. 在 Unity 中按下 **Play**，布置您的场景，然后按 `Ctrl+S` 保存项目（JSON 将被写入 `SavedProjects/` 目录）。
