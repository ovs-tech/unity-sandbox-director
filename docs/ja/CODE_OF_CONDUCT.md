# 🎬 行動規範 – Director Simulator コミュニティ

Director Simulator コミュニティへようこそ！私たちは、**フレンドリーで、互いを尊重し、創造的な**コミュニティが、皆の成長を助けると信じています。以下は、「映画制作者に優しい」遊び心のある雰囲気を提供し続けるための基本的なルールです。

---

## ✨ 基本原則
1. **互いを尊重する** – いかなる差別、いじめ、嫌がらせも禁止します。
2. **建設的であること** – フィードバックは具体的で前向きであり、他者の改善に役立つものであるべきです。
3. **オープンに共有する** – 学び、質問し、初心者を助けることを奨励します。
4. **安全を保つ** – 個人情報や機密性の高いコンテンツを共有したり、著作権を侵害したりしないでください。
5. **楽しみ、創造的であること** – 自分らしくあり、実験し、映画制作の過程を楽しんでください！

---

## 🚫 容認されない行為
- ヘイトスピーチ、人種差別、性差別、宗教差別、または性的指向に基づく差別。
- スパム、荒らし、または意図的な妨害。
- アダルトコンテンツ、暴力、または違法コンテンツの投稿。
- 個人への侮辱または攻撃。
