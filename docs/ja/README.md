# 🎬 ディレクター・シミュレーター：シーン・ビルダー (Director Simulator: Scene Builder)

**Unity Sandbox Director** – Unityエディタ内で直接**監督（ディレクター）の役割を果たす**ことができるUnity内のサンドボックスツールです。環境を構築し、キャラクターを配置し、カメラを設定し、シーンを録画して共有しましょう。動画編集の経験がなくても、シネマティックな映像を素早く作成したい**映画制作者、ゲームクリエイター、教育者**のために設計されています。

---

## 🚀 クイックスタート (Quick Start)
1. リポジトリをクローンし、Unity 2021.3+で開きます（URPを推奨）。
2. `Window → Placement System → Prefab Creator`を開き、最初のプレハブを作成します。
3. **MiniTimeline**（`Tools → Mini Timeline`ウィンドウ）を使用して、アニメーションやカメラの動きを作成し、動画をエクスポートします。
4. Unityで**Play**を押し、シーンを配置して、`Ctrl+S`を押してプロジェクトを保存します（JSONファイルが`SavedProjects/`に保存されます）。
