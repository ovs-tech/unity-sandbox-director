# 🎬 감독 시뮬레이터: 씬 빌더 (Director Simulator: Scene Builder)

**Unity Sandbox Director** – Unity 에디터 내에서 바로 **감독의 역할**을 수행할 수 있게 해주는 Unity 내의 샌드박스 도구입니다. 환경을 구축하고, 캐릭터를 배치하고, 카메라 위치를 지정하고, 씬을 녹화하고 공유하세요. 영상 편집 경험 없이도 시네마틱 영상을 빠르게 제작하고 싶은 **영화 제작자, 게임 제작자, 교육자**를 위해 설계되었습니다.

---

## 🚀 빠른 시작 (Quick Start)
1. 리포지토리를 클론하고 Unity 2021.3+에서 엽니다 (URP 권장).
2. `Window → Placement System → Prefab Creator`를 열어 첫 번째 프리팹을 만듭니다.
3. **MiniTimeline** (`Tools → Mini Timeline` 창)을 사용하여 애니메이션, 카메라 움직임을 만들고 비디오를 내보냅니다.
4. Unity에서 **Play**를 누르고 씬을 배치한 다음, `Ctrl+S`를 눌러 프로젝트를 저장합니다 (JSON 파일이 `SavedProjects/`에 저장됩니다).

## 📚 문서 (Documentation)
- **Docs 폴더** – GDD, Placement 시스템, MiniTimeline, 비동기 지속성 등에 대한 세부 정보가 포함되어 있습니다.
